(En-)Coding The Knowledge Graph Stack

11:15 – 12:40 CEST · Anatomisch Theater

Chair: Achim Reiz and Gregor Seifer

Online room

(En-)Coding The Knowledge Graph Stack: RDF, RDFS, SPARQL, SHACL, (YARR)RML

Knowledge Graphs help break down data silos by connecting heterogeneous sources into a shared, machine interpretable data layer. Too often, the stack driving this technology remains a mystery. This hands-on tutorial introduces the underlying technologies for building RDF-based knowledge graphs. In two sessions, participants will learn to understand and create graphs, apply ontologies, build constraints and ingest data. The first half of the tutorial, we will start with an introduction into triples, how they can be built with a simple text editor and how they already form a graph. Some of the terms carry a fixed semantics for building ontologies (RDFS, OWL) or are from already established vocabularies, and we will explore how to use them in a practical setting. Later that session, we explore SPARQL for extracting our newly created data. In the second half of the tutorial, we jump into ingestion and constraints. First, we create a data ingestion pipeline using YARRRML, a simpler subset of R2RML and RML, the standardized language for creating declarative pipelines. Later, we applied data quality checks with SHACL, ensuring that our graph data is structurally consistent, ensuring a high degree of data quality.
