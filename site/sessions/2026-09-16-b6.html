KGXL-Query: Extending SPARQL with Semantic Search and LLM functionality for Question Answering over Heterogeneous Data 🎖️

Tilahun Abedissa Taffa, Patrick Westphal, Debayan Banerjee and Ricardo Usbeck

In this paper, we introduce KGXL-Query, a new SPARQL functionality extension that embeds LLMs (Large Language Models) and semantic search directly into SPARQL, enabling hybrid inference where symbolic and non-symbolic methods coexist within a single, executable, and explainable framework. The quest to answer complex questions, those requiring both structured facts and contextual evidence from unstructured data, has shown a gap in knowledge systems: the incompatibility between symbolic and semantic inference. Knowledge Graphs (KGs) support formal, logically grounded querying via structured languages such as SPARQL. Conversely, LLMs and semantic text search offer vast coverage of real-world knowledge via vector-based similarity metrics. However, beyond using KGs for refining text or LLM results, and complementing missing information in KGs via LLMs or text search, there is less emphasis on accessing LLMs \& semantic search functionality through SPARQL. Moreover, existing Question Answering (QA) methods on heterogeneous data sources use RAG, data unification, and decompose-and-aggregate methods. The unifying approaches suffer from irreversible information loss; decomposition-driven methods are prone to cascading errors; and RAG methods lack explainability and are limited to shallow textual integration. Therefore, KGXL-Query paves the way by transforming the question to leverage the model rather than altering the data to fit it.

Navigating Schema Drift: Orchestrating Agents and Schema Discovery for Robust, Domain-specific Knowledge Graph Question Answering

Anton Diettrich, Dirk Friedenberger and Andreas Both

Knowledge Graph Question Answering (KGQA) over Large Language Models (LLMs) increasingly translates natural-language questions into SPARQL, yet most systems are statically optimized for a single benchmark and degrade abruptly under cross-domain transfer or schema evolution—a recurring obstacle for industrial Knowledge Graphs whose schemas continuously evolve. We present a KG-agnostic Text2SPARQL architecture that operates without task-specific fine-tuning. A meta-controller orchestrates a ReAct agent and an execution-validated, schema-guided fallback pipeline; both paths are grounded by a runtime FAISS-indexed Schema-Discovery service that absorbs structural change without offline retraining. The system is evaluated across four heterogeneous KGs: the open-domain DBpedia, a structurally complex Corporate dataset, and two versions of a proprietary railway metadata KG (TrackVideo, German: Streckenvideo), whose v1→v2 transition exhibits a Mapping Ratio of 0.255 and a normalized graph edit distance of 0.750, representing radical schema refactoring. The hybrid architecture attains a mean F1 of 47.6% with the lowest cross-domain standard deviation (2.33) among compared state-of-the-art systems and preserves performance between TrackVideo v1 (48.0%) and v2 (48.6%) despite the drift. A multi-model Quorum extension over heterogeneous LLM families further increases reliability, with absolute F1 gains of up to +7.0%. The findings support the HARP paradigm—hybrid agentic retrieval with execution-validated routing—for portable, schema-drift-resilient KGQA in production-grade settings.

GRMP: An open-source platform for automatic monitoring of linked data resources on the web

Stijn Denis, Marc Portier, Cedric Decruw and Stijn Deknudt

When publishing linked data-related resources through the web, it is strongly advised to actively monitor them and ensure they remain accessible, up-to-date and continue to provide data in the intended manner. Public registries and dashboards do exist, but they require active maintenance themselves lest they become outdated and provide incorrect information regarding the status of these resources. In order to support the management of their own LDES-servers and SPARQL endpoints and monitor the status of external web resources they consume, the scientific institute VLIZ (Vlaams Instituut voor de Zee – Flanders Marine Institute) developed GRMP (Graph Resources Monitoring Platform) in cooperation with Flemish IT and Software company Sirus. GRMP is an open-source and highly modular platform which allows for the automatic monitoring of linked data resources and web resources in general. GRMP is container-based and primarily consists of an orchestrator which manages and directs test suite containers based on configurations defined in one or more YAML-files. Due to its modular nature, users can rapidly develop new test suites in any desired programming language provided that they have been containerized and adhere to a few guidelines allowing for proper communication with the orchestrator. Additionally, the environment on top of which the system runs can be freely chosen, ranging from local deployments to integration with automation workflows like GitHub Actions. When running within GitHub Actions, additional features are available such as automatic issue creation resulting from failed tests. This talk by Stijn Denis from Sirus will provide an overview and demonstration of the current VLIZ GRMP implementation, highlighting how it can be rapidly customized and/or expanded upon for use by any organization to automatically run regularly scheduled test suites and monitor resources on the web.

Designing Enterprise Semantics: From Models to Meaningful AI [SP]

Sachin Khungar (GraphWise)

This talk explores the critical shift from viewing semantics as a purely technical exercise to understanding it as the foundation of shared meaning within an enterprise. By examining architectural patterns, common anti-patterns, and essential governance practices, the session outlines the Enterprise Semantic Design Pyramid and explains why successful initiatives must prioritize business strategy over technology. Attendees will gain a framework for navigating semantic challenges through established design principles and a maturity model — ultimately learning how to transform semantics from a technical feature into a core business capability that enables truly meaningful and autonomous AI.
