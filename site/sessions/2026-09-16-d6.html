Knowledge-driven Data Exchange and Validation Framework for Networked Smart Buildings

Xander Wilcke, Barry Nouwt, Sophie Lathouwers and Ronald Siebes

Building Automation and Management Systems offer centralized control and monitoring by integrating smart devices into the environment. Together, these provide building owners and stakeholders with data about energy consumption and other relevant characteristics which can, among others, be used for decision making and the automation of actions. However, due to the proliferation of different protocols and ecosystems, it often remains challenging to seamlessly aggregate and analyse the data streams provided by the connected devices. To overcome these problems, we introduce a knowledge-driven data exchange and validation framework, built upon Semantic Web technologies, that a) facilitates the transparent flow of graph data between smart devices, b) validates these data and generates reports on detected anomalous behaviour in real-time, and c) aggregates and displays the data and any derived insight on dashboards and other interactive web-accessible interfaces. Our framework consists of two core components: the Knowledge Engine, which acts as an information broker and translation layer between device-specific languages and RDF, and the Knowledge Validator, which continuously monitors these RDF streams and reports on deviations from nominal behaviour. We evaluate our framework via requirement-based testing and demonstrate its functionality in a real-world case study in the smart buildings domain, showing that it can facilitate seamless communication between devices of different make and model and that it can help building owners recognize abnormal device behaviour.

Smart Buildings, Smart Future: Semantic Data Integration for Smart Buildings including a Federated Data Model

Apostolos Barekas, Pieter Pauwels and Stefan Hoekstra

Our buildings are getting more and more data-driven, thus providing the potential of making them smarter and ‘more intelligent’. However, 90% of available IoT and sensor data in building systems currently tends to go to waste, and remains unused. This operational data loss is caused by data fragmentation, the use of isolated and often proprietary closed systems, and the absence of standardized data exchange protocols, obstacles that consistently prevent building owners from deploying affordable, scalable solutions to create facilities that are more effectively used. To solve this problem, the Dutch public-private partnership initiative SuGeST (Smart Buildings, Smart Future) is establishing an open, standard-based digital backbone for commercial real estate. By leveraging a decentralized, federated data model and semantic middleware, SuGeST unifies highly diverse data sources, including Building Information Modeling (BIM), Building Management Systems (BMS), and time-series sensor data, while securely keeping all data at their original sources. Built on FAIR data principles and closely aligned with international ontologies, such as Brick, SAREF, and BOT, the project delivers practical data structuring guidelines alongside an independent data layer proof-of-concept. Integration is achieved using a system integration approach. The framework is validated across two smart living labs at the Technical Universities of Delft (The Green Village) and Eindhoven. By improving data access, the independent layer simplifies algorithm training, making it easier to deploy specific MPC hardware and software as a building's base control system based on its semantic parameters. The independent layer aims to demonstrate a 20-25% reduction in system implementation time alongside a 10–20% improvement in energy efficiency and indoor climate comfort. Ultimately, the project provides a definitive, actionable roadmap for real estate owners, installers, and software vendors to claim true data ownership at the source and accelerate the sustainable transformation of the built environment.

From Ontology Design to Operationalised Interoperability: The Semantic Resource Interface (SRI)

Henon Mengistu Lamboro, Cécile Rabrait, Jan Mayer and Dušan Gabrijelčič

Semantic technologies are widely recognised as a means to achieve interoperability in heterogeneous digital ecosystems. However, many ontology-driven initiatives remain limited to conceptual modelling activities and fail to demonstrate how semantic models can be integrated into operational data exchange infrastructures. This work presents the Semantic Resource Interface (SRI), an interoperability component developed within the Horizon Europe RESONANCE project to enable semantic integration across buildings, energy management systems, electric vehicle charging infrastructure, IoT devices, and flexibility services. In industrial environments, these systems operate in isolated silos, having heterogeneous data models, APIs, naming conventions, and various interpretations of identical concepts, which makes semantic interoperability both challenging and costly. Beyond integration at the data level, a key challenge is enabling a continuous bridge between heterogeneous but non-homogenised data sources and downstream energy applications and services. To overcome this challenge at an operational level, we designed the RESONANCE ontology that contains five ontology modules that reuse existing standard energy domain ontologies like SAREF (The Smart Applications REFerence Ontology) and its extensions SAREF4ENER and SAREF4BLDG. Then we implemented a shared, common semantic interoperability component, the Semantic Resource Interface (SRI).

Schiphol’s Linked Data Approach for Aviation Asset Information Exchange

Ad Ruijl and Jakko Heinen

Since 2019, Amsterdam Airport Schiphol has been building a semantic foundation for exchanging and managing asset information across systems, projects and contractors. Asset data is exchanged using IFC-XML messages and modelled with the Data Dictionary Schiphol (DDS), a linked-data ontology describing asset types, properties, documents, locations and definitions in a standardised way. The resulting RDF data is stored in Schiphol’s Central Data Facility, known as the CDV, which acts as a semantic source of truth for operational asset information. This use case shows how semantic technology is applied in a complex aviation asset environment where reliable information is essential for design, handover, maintenance and decision-making. With the introduction of the Assetviewer in 2025, the CDV becomes visually accessible to end users. Users can explore assets, properties, locations, documents and definitions directly from the linked-data layer, making semantic models useful beyond system integration alone. Together with Wistor, Schiphol is extending this foundation towards IFC model viewing, BIM exploration, project-specific information windows, ILS automation and contextual SHACL validation. A key next step is DDS 4.0, which separates conceptual meaning, physical data structures and validation logic more explicitly, drawing on principles from MIM and NEN 2660. This makes the model more compact, flexible and maintainable, while enabling stronger validation of project deliverables. The presentation demonstrates how linked data, ontologies and SHACL can support practical asset information exchange in aviation, and how semantic technology can help verify whether projects have delivered the asset data that was agreed contractually and operationally.
