Abstract

Our buildings are getting more and more data-driven, thus providing the potential of making them smarter and ‘more intelligent’. However, 90% of available IoT and sensor data in building systems currently tends to go to waste, and remains unused. This operational data loss is caused by data fragmentation, the use of isolated and often proprietary closed systems, and the absence of standardized data exchange protocols, obstacles that consistently prevent building owners from deploying affordable, scalable solutions to create facilities that are more effectively used. To solve this problem, the Dutch public-private partnership initiative SuGeST (Smart Buildings, Smart Future) is establishing an open, standard-based digital backbone for commercial real estate. By leveraging a decentralized, federated data model and semantic middleware, SuGeST unifies highly diverse data sources, including Building Information Modeling (BIM), Building Management Systems (BMS), and time-series sensor data, while securely keeping all data at their original sources. Built on FAIR data principles and closely aligned with international ontologies, such as Brick, SAREF, and BOT, the project delivers practical data structuring guidelines alongside an independent data layer proof-of-concept. Integration is achieved using a system integration approach. The framework is validated across two smart living labs at the Technical Universities of Delft (The Green Village) and Eindhoven. By improving data access, the independent layer simplifies algorithm training, making it easier to deploy specific MPC hardware and software as a building's base control system based on its semantic parameters. The independent layer aims to demonstrate a 20-25% reduction in system implementation time alongside a 10–20% improvement in energy efficiency and indoor climate comfort. Ultimately, the project provides a definitive, actionable roadmap for real estate owners, installers, and software vendors to claim true data ownership at the source and accelerate the sustainable transformation of the built environment.
