Abstract

Since 2019, Amsterdam Airport Schiphol has been building a semantic foundation for exchanging and managing asset information across systems, projects and contractors. Asset data is exchanged using IFC-XML messages and modelled with the Data Dictionary Schiphol (DDS), a linked-data ontology describing asset types, properties, documents, locations and definitions in a standardised way. The resulting RDF data is stored in Schiphol’s Central Data Facility, known as the CDV, which acts as a semantic source of truth for operational asset information. This use case shows how semantic technology is applied in a complex aviation asset environment where reliable information is essential for design, handover, maintenance and decision-making. With the introduction of the Assetviewer in 2025, the CDV becomes visually accessible to end users. Users can explore assets, properties, locations, documents and definitions directly from the linked-data layer, making semantic models useful beyond system integration alone. Together with Wistor, Schiphol is extending this foundation towards IFC model viewing, BIM exploration, project-specific information windows, ILS automation and contextual SHACL validation. A key next step is DDS 4.0, which separates conceptual meaning, physical data structures and validation logic more explicitly, drawing on principles from MIM and NEN 2660. This makes the model more compact, flexible and maintainable, while enabling stronger validation of project deliverables. The presentation demonstrates how linked data, ontologies and SHACL can support practical asset information exchange in aviation, and how semantic technology can help verify whether projects have delivered the asset data that was agreed contractually and operationally.
