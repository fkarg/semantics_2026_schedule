The Universal CPQ Interface: Exploring Product Configuration Models via MCP and Knowledge Graphs

Marcel Fröhlich, eccenca GmbH

10:20 – 11:50 CEST · Kraakhuis

Session time; individual talk times are not specified in the timetable.

Chair: Milan Dojchinovski

Online room

Abstract

Product configuration models in CPQ systems are typically proprietary and opaque, creating vendor lock-in and limiting flexibility. This talk presents a solution using knowledge graphs and the Model Context Protocol (MCP) to represent these models in a vendor-neutral, standardized format. By exposing configuration logic as a knowledge graph, organizations can explore models through MCP tools and translate them into any CPQ system’s language—without being tied to a specific vendor’s proprietary format.

We discuss how this general representation serves as a universal interface for product configuration knowledge, breaking vendor dependencies while maintaining full access to the underlying logic. The talk covers the technical foundation, practical benefits for model exploration and migration, and its contribution to interoperable knowledge management in enterprise environments.
