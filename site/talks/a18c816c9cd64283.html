Abstract

Modern language models increasingly recover signals of relatedness from text alone. They can support related-item ranking, entity clustering, and recommendation-style workflows without a separately modeled graph. For the knowledge graph community, this creates a timely and practical question: when do explicit graph relationships still add value beyond what strong text embeddings already capture? This paper approaches that question carefully. It does not treat knowledge graphs as globally replaceable. Many KG roles — including semantic integration, provenance, governance, validation, querying, and domain modeling — remain distinct from embedding-based retrieval. Instead, we focus on a narrower class of use cases where relationship value is representational: recommendation, discovery, similarity search, related-item ranking, and relation recovery. In these settings, the question becomes measurable: do explicit relationships add recoverable signal beyond node text? We introduce a relation-dependent diagnostic framework for measuring this boundary. We call the underlying phenomenon language-model encroachment: the growing ability of text-based representations to approximate relational signal traditionally supplied by explicit graph structure. Using an OpenAlex-derived scientific KG case study, we repeat the diagnostic across relation types, dataset slices, publication years, and text encoders. In each setting, text-derived and graph-derived representations are evaluated on the same held-out relationship recovery task. The results show that the graph–text boundary is not fixed. Some relation types are largely recoverable from text for this task. Others retain distinctive graph-derived signal. The contribution is a practical diagnostic for KG engineering: if a relationship type adds signal beyond text, it may justify graph-engineering effort; if it does not add measurable signal, a text-first system may be sufficient for that task. This does not mean a KG is unnecessary overall, because many KG roles remain justified independently of embedding performance.
